Aim:

Evaluate the usability of the Spotify-style 5-screen wireframe (Splash, Login/Signup, Home, Music Detail, Subscription) to identify usability issues, prioritize fixes, and validate improvements with measurable metrics.

Algorithm:

1.Define the scope, target users, and 3 core tasks (Sign in, Find & Play a song, Subscribe).

2.Create Balsamiq-style low-fidelity wireframes for the 5 screens and annotate interaction points.

3.Perform a heuristic review using Nielsen’s 10 Usability Heuristics, logging usability issues and assigning severity levels (1–4).

4.Build an interactive mid-fidelity prototype of the fixed high-severity screens.

5.Recruit 6–10 representative users.

6.Conduct moderated usability tests. For each user, perform the 3 tasks and collect task success rate, task completion time, errors, SUS score, and qualitative feedback.

7.Aggregate the collected metrics and map the identified issues to the relevant heuristics. Prioritize fixes as Must / Should / Could.

8.Implement the recommended design changes in the prototype.

9.Re-test the improved prototype using the same tasks with 5–8 users or through A/B testing, and collect post-change metrics.

10.Compile the final report containing findings, before/after metrics, screenshots, and prioritized recommendations.
